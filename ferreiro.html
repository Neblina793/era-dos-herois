Ferreiro: Sistema de Forja

As regras sobre armas obra-prima superiores e seu uso servem para acrescentar a diversificação existente do Livro do Jogador de D&D 5.5 de 2024. Usaremos no texto a sigla “OP”, para os itens obra-prima.

Que fique bem claro: não recomendamos a cumulação do melhoramento de itens obra-primas superiores junto aos mágicos no mesmo cenário de jogo. Primeiro porque, se existem itens mágicos, não haverá um contexto histórico forte para que sejam desenvolvidos cumulativamente itens obra-prima superiores. Segundo porque itens obra-prima costumam sair mais barato que os mágicos, ideais para campanhas com poucos tesouros ou que não se quer que faça a diferença só os personagens talentosos, e não penduricalhos ambulantes de itens mágicos. Se você gosta de campanhas recheadas de “Desagas Douradas de Brisbeath Exóplica Covetas e Chanfros de Umbra III”, esse artigo não é para você.

Em cenários com baixa magia ou sem a tradição de armas mágicas, é evidente que sejam produzidos armas e armaduras superiores para aproveitar o cenário de maneira alternativa. Nestes casos existem os níveis de obra-prima, cada um com seus benefícios e custos. Os valores para os benefícios são cumulativos — uma espada longa OP 2 custa 765 PO, 15 pelo valor base da arma mais 250 pelo OP 1 e outros 500 pelo OP 2.

Para usar esta tabela, o PC inicial de itens obra-prima, para resultar em valores mais fáceis de lembrar. Utilize as regras normais para criação de armas, armaduras e munições vistas no Livro do Jogador. A CD para criar ou melhorar itens obra-prima acima do nível de progressão aumenta em 4 pontos por nível.

Materiais Especiais

Vários cenários de fantasia possuem metais ou materiais superiores, usados na confecção de itens, como o Mithral ou o Adamante. Temos forjado custos de materiais especiais, e seus efeitos NÃO se acumulam com as melhorias de Obra-Prima equivalentes ao do material. Tais itens podem receber níveis de obra-prima normalmente.

A CD de Ofícios para torná-lo obra-prima ou para melhorá-lo aumenta em +2 por raridade e tem como modificador o Nível de OP + o valor conforme o Nível. Exemplo: um Mithral é considerado um material Raro. A CD para criar uma Armadura de Mithral de Nível 3 de OP para o Nível 4 será:

8 + 6 + 5 = 19 (Base + Raridade + Nível de OP seguinte +1).

    1-🧱 Escolha a arma base:

    Primeiro, você pega uma arma normal do Livro do Jogador.

    Exemplo:

  • Espada longa = 15 PO

    • 2. 📈 Escolha o nível de Obra-Prima (OP)

    Cada arma pode ter níveis de melhoria:

    Exemplo:

  • OP 1
  • OP 2
  • OP 3
  • etc.

    • ⚠️ Importante:

  • Os bônus são cumulativos
  • Quanto maior o nível, mais caro e difícil

    • 3. 💰 Calcule o custo

    O custo é:

    Arma base + custo de cada nível de OP

    Do texto:

  • OP 1 = +250 PO
  • OP 2 = +500 PO
  • (e assim por diante, aumentando por nível)

    • ✅ Exemplo:

    Espada longa OP 2:

  • base = 15 PO
  • OP 1 = +250 PO
  • OP 2 = +500 PO

    • 👉 Total = 765 PO

    4. 🎲 Defina a CD de criação

    A dificuldade (CD) aumenta conforme o nível.

    Do texto:

    A CD aumenta em +4 por nível acima do normal

    Ou seja:

  • OP 1 → CD base
  • OP 2 → CD +4
  • OP 3 → CD +8
  • etc.

    • 5. 🔨 Faça o teste de criação (Ofícios)

    Você usa:

  • Perícia de Ofício (ou equivalente)
  • Ferramentas adequadas (ferreiro, armeiro, etc.)

    • Se passar na CD → cria a arma

    Se falhar → perde tempo/material (depende da mesa)

  • Não acumulam com bônus equivalentes de OP

    🧠 Regra importante (equilíbrio)

    O próprio texto diz:

    👉 Não misture itens mágicos + OP Porque:

  • OP fica mais barato
  • Pode quebrar o balanceamento

    • ⚡ RESUMO RÁPIDO (pra usar na mesa)

  • Escolhe arma base
  • Escolhe nível OP
  • Soma custos (base + níveis)
  • Calcula CD (+4 por nível)
  • Aplica material (+2 se raro)
  • Faz teste de Ofício
  • Produz arma

    💰 Estrutura do custo
    O custo segue essa lógica:
    Custo total = arma base + soma dos níveis de OP

    👉 Os custos são cumulativos e crescentes

    📊 Progressão real:

    • OP 1 → +250 PO
    • OP 2 → +500 PO
    • OP 3 → +750 PO
    • OP 4 → +1000 PO (provável padrão)

    💡 Ou seja: Cada nível adiciona +250 PO a mais que o anterior

    🔥 Fórmula prática (Automação):
    Custo OP = 250 × nível × (nível + 1) / 2

    Exemplo OP 3: 250 × 3 × 4 / 2 = 1500 PO

    ⚠️ Impacto no jogo: OP baixo é acessível; OP alto é caro, mas ainda mais barato que item mágico.

    🎲 2. CD (DIFICULDADE) — COMO ESCALA

    📈 Regra base:

    A CD aumenta em +4 por nível de OP

    📊 Progressão:

  • OP 1 → CD base
  • OP 2 → +4
  • OP 3 → +8
  • OP 4 → +12

    • 🧠 Interpretação: Cria uma curva onde é fácil começar, mas muito difícil chegar em níveis altos, impedindo spam de itens fortes.

    📊 3. PROGRESSÃO — O CORAÇÃO DO SISTEMA

    🔁 Tudo é cumulativo:

    • Custo acumula
    • CD acumula
    • Benefícios acumulam

    🧩 Na prática: Você NÃO cria direto OP 3. Você faz o OP 1, melhora para OP 2 e depois para OP 3.
    🔥 Consequência: Tempo maior, risco maior (mais testes) e investimento contínuo. O item evolui com o personagem.

    🪨 4. MATERIAIS ESPECIAIS

    ⚙️ Exemplos: Mithral, Adamante.

    ❗ Regra CRÍTICA: Eles NÃO acumulam com bônus equivalentes de OP.

    🧠 Tradução: Se o material já dá um bônus parecido, você não ganha o bônus duas vezes.

    📈 CD com materiais: +2 na CD por raridade.

    • Material raro → +2
    • Muito raro → pode ser +4 (dependendo da mesa)

    ⚖️ Impacto: Você escolhe entre melhorar com OP OU usar material especial, evitando abusar dos dois.

    🔥 5. SISTEMA COMPLETO (VISÃO REAL)

    🧩 Os 4 pilares:

    • Economia: Progressiva, controla o acesso.
    • Dificuldade: Escala rápido, evita abuso.
    • Progressão: Evolução gradual, dá identidade ao item.
    • Limite de Poder: Material ≠ OP stacking livre.
